# Third-party notices

Threadbound's own code is MIT licensed (see `LICENSE`). The production build
bundles the open-source packages below, and an XR session loads the WebXR input
profile models at runtime. Versions are the ones `package-lock.json` installs
(checked Oct 23, 2026).

The MIT, ISC, BSD and OFL licenses below ask that the copyright notice and the
license text travel with copies. The minified bundle keeps none of the packages'
license comments, so this file carries them: the table gives every copyright
line, and [License texts](#license-texts) reproduces each license in full. This
file lives in the source repository, and the deployed page serves it as
`THIRD_PARTY_NOTICES.txt` beside `LICENSE.txt` (copies in `public/`, which the
build emits into `dist/`).

Most packages also ship their license text in their npm package under
`node_modules/<name>/`. Not all do: `yoga-layout` 3.2.1 declares MIT in its
`package.json` but its npm package has no license file (the MIT text below
covers it); `@drawcall/uikitml` 0.1.8 declares no license at all; and
`@pmndrs/uikit-lucide`'s license file holds only its own MIT terms, not the ISC
text of the Lucide icons inside it (reproduced below).
