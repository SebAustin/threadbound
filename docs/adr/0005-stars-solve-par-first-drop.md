# Stars reward the solve, economy and foresight; the thread limit is par + 1

21 of the 24 levels capped threads at par, so three stars were automatic and one star was impossible. A solve now earns one star for solving, one for using par threads or fewer, and one for solving on the first drop since the level loaded or restarted. Every level's thread limit becomes par + 1. Thrift and thinking ahead both pay, and every tier is reachable on every level. With only one spare thread the existing level proofs stay valid: a cheaper alternative solution that uses the spare thread is fine, because it earns fewer stars.

**Considered Options:** par + 2 with the old rule (it needs new proofs that try spare threads); the new rule with the caps left at par (two of three stars stay automatic on 21 levels); a song star (frame-rate dependent, see 0004).

**Consequences:** stars saved before this change keep their old meaning; judges start fresh. A skipped level earns no stars and stays unsolved.
